# Релиз-ноутс. M4. Один процесс

Веха M4. Фикстура и файловая выгрузка проходят через один `collect`, затем через прежний `build`. Формулы не менялись.

Появилось:

- каталог `src/dashboard/connectors`: `fixture` отдаёт готовый canonical JSON, `file` собирает его из выгрузки Jira-формы;
- `python3 -m dashboard run` пишет слепок; `--serve` открывает экраны только на `127.0.0.1`;
- чистый прогон золотых случаев M1 совпадает с записанными числами;
- выгрузка `fixtures/m4/file-sprint` совпадает с `expected.canonical.json`, и слепок от неё побайтно равен прямому build этого файла;
- режим `live` останавливается и сеть не открывает.

На `GET /api/sprint` у файловой выгрузки закрытие до срока расходится по полночи Москвы, снятая задача имеет scope `removed`, а сумма `storyPointsAtAdd` в burndown равна 8: оценка на входе 5, текущая 8.

Не входит: живая Jira, Docker, инкремент manifest, токен на нелокальный адрес, React.
