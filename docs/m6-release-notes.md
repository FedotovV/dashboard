# M6. Мастер настройки

Форма на `http://127.0.0.1:8765/setup` читает и пишет тот же `team.yaml`. Схема и каталог формул не изменились.

Подключение: `python3 -m dashboard serve --snapshots … --team <id> --config path/to/team.yaml`. Необязательный `--manifest` только сравнивается с хешем правил. `run --serve` подключает файл команды сам.

Запись отклоняет секрет в файле, чужой id команды, версию формулы кроме 1, `Blocks` в связях и окно дня, которое не сходится с `hoursPerDay`. Ошибка файл не меняет.

Если календарь, статусы, эпики или состав задач расходятся с manifest, ответ говорит, что следующий `build` остановится без `--accept-recompute`. Сам мастер manifest и слепок не пишет. Кнопки сборки на экране нет.

Не входит: портфель команд, SSO, React, живой Cloud, кнопка пересборки.
