# Ревью экрана M3

Повторное чтение `src/dashboard/api`, `src/dashboard/edits` и `web/sprint.css` против каталога и `docs/m3-plan.md`. Прогон: `python3 -m pytest -q` — 101 тест, `python3 scripts/check_contracts.py` — `contracts ok`.

## Что сходится

- Страница и `GET /api/team` читают файл. Модули `api` не импортируют `dashboard.metrics` и не вызывают `compute`.
- Плашка unknown стоит выше часов и берёт процент из слепка.
- Кольцо — доли двух сумм секунд. При `timing = none` кольца нет.
- Часы не названы утилизацией, доля к ёмкости не покрашена как цель.
- У человека ключ и путь к голове из `paths`. Неразобранный путь выделен.
- Релиз и заметка живут в `edits.json`. Второй build их не стирает. `PUT` не пишет слепок.
- Чужой эпик даёт предупреждение. Пустой список эпиков — плашка.
- Завершение к старту — ссылка на уже посчитанное «N из M».
- Serve по-прежнему слушает только `127.0.0.1`. Кнопки сборки нет.

## Что поправлено на ревью

Список секунд по дням свёрнут: на демо он длинный и закрывал кольцо. Доля и параллельность на экране — два знака, полное число остаётся в слепке. Имя feature lead подставляется из строки человека, если id совпал; в слепке по-прежнему id.

Других расхождений с каталогом ревью не нашло. `collect`, Docker и живая Jira не начаты.
