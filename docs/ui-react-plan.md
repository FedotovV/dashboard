# UI на React

Серверные экраны «Спринт», «Период» и «Настройка» уже читают слепок. Этот план переносит ту же картинку в React и не меняет формулы. Число на экране по-прежнему берётся из JSON. Браузер не вызывает `compute`.

Стек: React и Vite на JavaScript. TypeScript не подключаем. Отдельный набор компонентов вроде Tremor не становится источником чисел: линия графика строится по точкам слепка.

Направление внешнего вида ещё не выбрано. Ниже пять макетов одного и того же спринта. Сборка компонентов начинается после выбора одного.

## Что остаётся как есть

- `GET /api/sprint`, `GET /api/team`, `GET /api/metrics/{id}`, запись правок и мастера.
- `null` не рисуется нулём. Скрытый блок не оставляет пустую шкалу.
- Нет `riskScore`, карточки утилизации, цветовых порогов и вердикта «план достижим».
- Выделение только у того, на что смотреть: добавление и снятие состава, пауза, отмена, блокер, пустая оценка, остаток выше идеала.
- Кнопки сборки нет. Секрет на экран не выходит.

## Пять направлений

Один и тот же набор фактов: закрыто 11 из 18, добавлено 3, снято 1, цикл, поток, сгорание, список «смотреть сейчас».

| | Имя | Когда брать |
| --- | --- | --- |
| 1 | Бумага | Продолжение текущего экрана: тёплый фон, крупный заголовок, мало оболочки. Удобно читать, а не «сидеть в панели». |
| 2 | Линейка | Плотный рабочий стол на каждый день. Слева разделы, числа одной строкой, таблица задач сразу на первом экране. |
| 3 | Сводка | Один главный факт крупно, остальное короткими абзацами. Для разбора на планёрке, не для долгой работы в таблице. |
| 4 | Доска | Боковое меню и белые карточки. Проще всего вырастить «Период» и «Настройку» в ту же оболочку. Синий только у текущего раздела, не у оценки. |
| 5 | Ночная | Та же сетка, что у доски, тёмный фон. Латунь помечает, куда смотреть, и не значит «плохо». |

## Сборка после выбора

Каталог `frontend/` появляется на шаге 0. Серверный HTML в `web/` живёт, пока React не показывает те же блоки. Стили — один файл токенов выбранного направления, без второй темы.

- [ ] Шаг 0. Каркас. Vite, React, прокси `/api` на текущий `serve`. Страница читает `GET /api/sprint` и показывает имя спринта из ответа.
- [ ] Шаг 1. Оболочка. Навигация «Спринт», «Период», «Настройка». Шапка и плашка качества данных.
- [ ] Шаг 2. Состав, поток, цикл и ожидание.
- [ ] Шаг 3. Блокеры, команда, таблица задач.
- [ ] Шаг 4. Сгорание и тренд. SVG по `detail.points` и `trend.sparkline`.
- [ ] Шаг 5. Экран «Период» из `GET /api/team`.
- [ ] Шаг 6. Мастер. Та же запись, что `POST /api/setup`. Токен записи — поле формы, не cookie.

Проверка шага 0 — ответ API не подменяется в браузере. Дальше каждый шаг сверяет видимый текст с полями слепка, как сейчас делает `tests/test_sprint_page.py` для серверного HTML.
