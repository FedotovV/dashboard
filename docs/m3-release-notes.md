# Релиз-ноутс. M3. Экран «Период» и правки

Веха M3. Страница `/period` читает слепок M1. Формулы не менялись.

Появилось:

- плашка неразобранных задач выше кольца часов в статусе;
- кольцо «свои / из прошлого», параллельность и доля к ёмкости без цветовой цели;
- люди периода: ключ задачи и путь к голове эпика;
- список эпиков с релизом и заметкой;
- `PUT /api/edits` и форма на localhost пишут `edits.json` по схеме правок и не переписывают слепок.

Заметка, записанная до первого build, остаётся после второго. Заметка после записи слепка видна на экране из файла правок; байты этого дня не меняются.

Не входит: `collect`, Docker, живая Jira, токен на нелокальный адрес.
