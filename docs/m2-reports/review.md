# Ревью экрана M2

Повторное чтение `src/dashboard/api` и `web/` против каталога и `docs/m2-plan.md`. Прогон после правки выбора даты: `python3 -m pytest -q`.

## Что сходится

- Страница и `GET /api/sprint` читают файл. `compute` не импортируется и на запрос не вызывается.
- `null` на экране — прочерк. Ноль показывается только если он лежит в слепке: счётчик потока, пустой список человека.
- Burndown отсутствует, когда покрытие SP не `full` или `value` равен `null`. Линия строится из `detail.points`, новая идеальная точка не считается.
- Завершение к старту — «N из M» из `detail`, не новое деление. Неполный membership оставляет состав пустым.
- Спарклайн — массив слепка. Бейдж прошлого спринта есть только вместе с `trend.previous`.
- Раскрытие цикла показывает ключи, секунды и причины из слепка. Текст «Как считается» — поле `explain`.
- Serve слушает `127.0.0.1`, файл не пишет, `PUT` не принимает.

## Что поправлено на ревью

Флаг `--date` печатал адрес, но без query сервер всё равно открывал самый поздний файл. Теперь этот день — день по умолчанию. Тест `test_date_flag_selects_that_file_when_the_query_is_empty` это держит.

Других расхождений с каталогом ревью не нашло. Экран периода, часы в статусе и запись правок по-прежнему не начаты.
