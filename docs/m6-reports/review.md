# M6. Проверка

Команды: `python3 -m pytest` (144 теста) и `python3 scripts/check_contracts.py` (`contracts ok`). Браузер не поднимался. Страница и запись читались через `urllib` с `127.0.0.1`.

Сошлось:

- форма показывает «Платёжная карта» и имя `JIRA_TOKEN`; значение токена из окружения не попадает в HTML, в ответ и в текст ошибки;
- `PUT` с новым названием пишет YAML, хеш правил тот же, байты manifest и слепка те же;
- смена эпика ставит `needsAcceptRecompute`, байты manifest и слепка те же;
- отклонённые тела оставляют байты `team.yaml`: версия формулы, чужой id, `Blocks`, окно дня, эпик в двух списках, `ui.hide` вне списка, секрет в адресе и в поле, ключ `token`, live без `sprintId`, Cloud без `jiraAccountId`;
- полный POST формы сохраняет хеш; повторный дамп не меняет байты файла;
- битый manifest отвечает 422 и файл команды не переписывает;
- без `--config` маршрут `/setup` отвечает 404; на экране спринта нет `<button`, в том числе когда конфиг подключён.
