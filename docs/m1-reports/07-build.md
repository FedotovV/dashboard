# Отчёт. Шаг 7. Сборка

## Что проверялось

`tests/test_build.py` на примерах схемы:

- первый build пишет слепок, байты `edits.json` те же, релиз и заметка видны в строке эпика, в тексте цикла есть 900;
- повторный build не открывает файл на запись;
- другие байты входа при том же дне дают код 4, старый слепок цел;
- чужой `ruleHash` даёт код 3, каталога слепка нет, правки не тронуты;
- `--accept-recompute` записывает новый хеш и пустой `timings`;
- `metrics` не открывает файлы и не импортирует `snapshotstore` / `orchestrator`, `config` не импортирует `metrics`.

`tests/test_gold.py` гоняет `fixtures/m1/`. Ожидаемые снимки написаны по каталогу: 14400 с и медиана 0,5 у переоткрытия, две стороны полуночи Москвы, масштаб 36000 → 28800, add на 9 сентября и remove на 13-е, canceled в знаменателе, burndown от `storyPointsAtAdd`, поле SP выключено, темп `null` в 10:00 первого дня. `prevSprint` берётся из положенного рядом слепка прошлого спринта, день без файла в `sparkline` не появляется. `rules-changed` проверяет код 3, а не равенство снимка: слепок не пишется.

Хеш bundle в слепке считается отдельно от ожидаемого файла и сверяется с каноническим JSON.

## Команды

```bash
python3 -m pytest tests/test_build.py tests/test_gold.py -q
```
