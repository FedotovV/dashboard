# M7. Проверка

Команды: `python3 -m pytest` (149 тестов) и `python3 scripts/check_contracts.py` (`contracts ok`). Браузер не поднимался. Запись и отказ читались через `urllib`. Адрес проверки — `127.0.0.2`: для процесса это не `127.0.0.1`, с хоста он по-прежнему loopback. `docker compose config` здесь не запускался: демона Docker нет. Файл `compose.yaml` проверен как YAML.

Сошлось:

- без токена `10.1.1.1` и пустая переменная дают код 2, сокет не открывается;
- `GET` на `127.0.0.2` открыт, страница просит токен и само значение не показывает;
- `PUT` без заголовка, с `?token=`, со схемой `Basic` и с чужим Bearer отвечает 401, байты правок, YAML и слепка те же;
- верный Bearer и поле формы пишут заметку и название команды, токена в файлах нет;
- на `127.0.0.1` тот же токен, переданный в процесс, запись без заголовка принимает, поля пароля на форме нет;
- `compose.yaml` публикует порт на `127.0.0.1`, слушает `0.0.0.0`, берёт `DASHBOARD_TOKEN` из окружения. В Dockerfile этого значения нет.
