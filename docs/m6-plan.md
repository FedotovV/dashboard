# M6. Мастер настройки

M5 влит: живой сбор Server / Data Center пишет тот же bundle, manifest запечатывает `terminal`, контейнер один. Этот шаг — форма над тем же `team.yaml`. Новых полей схемы и новых формул нет.

## Статус

- [x] План
- [x] `GET /setup` и `GET /api/setup` читают подключённый `team.yaml`
- [x] `PUT /api/setup` и форма `POST /api/setup` пишут тот же файл после схемы и инвариантов
- [x] Секрет в файл не попадает: имя `authEnv`, не значение переменной
- [x] Смена календаря, статусов, эпиков или состава задач ставит `needsAcceptRecompute`, manifest и слепок мастер не пишет
- [x] Без `--config` маршрутов настройки нет. Кнопки сборки на экране спринта нет

Отчёт: [m6-reports/review.md](m6-reports/review.md).

## Команда

`serve` и `run --serve` по-прежнему слушают только `127.0.0.1`.

```bash
python3 -m dashboard serve \
  --snapshots var/snapshots \
  --team payments-card \
  --config path/to/team.yaml \
  --manifest var/manifest.json
```

`run --serve` подключает тот же `--team` как конфиг и тот же `--manifest`, если он передан. Адрес формы: `http://127.0.0.1:8765/setup`.

## Что пишет форма

Разделы те же, что в [mapping-guide.md](mapping-guide.md): команда и состав, календарь, период, Jira, статусы, эпики и связи, состав задач, параметры формул. `team.id`, `version` и `catalogVersion` на форме не редактируются. Версии `cycleTime`, `hygiene` и `classification` остаются 1.

`PUT` заменяет файл телом запроса. Форма меняет только присланные поля и сохраняет остальные, включая пометки `links`, которые v1 не читает.

Запись проходит `team.schema.json`, инварианты `scripts/check_contracts.py` и `load_team`. Для `live` нужны `sprintId`, имя `authEnv` и `http(s)` `baseUrl`. `Blocks` в `linkTypes` отклоняется. `ui.hide` по-прежнему не принимает плашки качества данных.

## Секрет

В дереве документа нельзя держать ключ вроде `token` или `password`. `authEnv` — имя переменной окружения. Если её значение непустое и встретилось строкой в документе, запись отклоняется. В `baseUrl` нет логина, пароля и секретного query. Текст ошибки само значение не повторяет.

## Хеш

Ответ содержит `ruleHash`, `manifestRuleHash`, `manifestState` и `needsAcceptRecompute`. Хеш тот же, что у `build`: календарь, статусы, таксономия, состав задач и версии формул. Расхождение с записанным manifest не переписывает manifest и не ставит `--accept-recompute` само. Следующий `build` останавливается прежним кодом 3. Состав людей в этот хеш не входит: так уже считает движок.

Повторная запись того же документа не меняет байты `team.yaml` после первого нормализованного дампа. Слепок дня мастер не открывает на запись.

## Что не делается

Кнопка пересборки, правка чисел метрик, новая версия формулы, React, SSO, токен на нелокальный `PUT`, вторая команда, Cloud-клиент, Confluence, мессенджер, GitLab.
