# Релиз-ноутс. M1. Движок

Веха M1. Считается канонический JSON и `team.yaml`. Экрана, коннектора и живой Jira нет.

## Сделано

- Движок формул v1: цикл и ожидание, состав спринта, завершение к старту, гигиена, блокеры, загрузка людей, burndown, классификация, часы в статусе, список эпиков.
- Сборка `python -m dashboard.orchestrator.build`: слепок пишется один раз, `edits.json` не переписывается, чужой хеш правил останавливает build.
- В схему снимка добавлены `dueDate`, `closedBeforeDue`, `detail`, `explain`, `trend` и хеш `bundle`. В календарь — необязательный `breakStart`.
- Золотые пары в `fixtures/m1/`: полночь Москвы, переоткрытие цикла, масштаб дня, классификация, день 3 и день 7 состава, нет SP, сдвиг оценки, нулевой темп, write-once, целые правки, отказ при смене карты статусов.
- Проверка: `python3 scripts/check_contracts.py` печатает `contracts ok`. `python3 -m pytest` — 66 тестов. Отчёты по срезам — в `docs/m1-reports/`.

## Не входит в эту веху

Каталоги `connectors`, `api`, `web`. Команды `collect` и `serve`. Docker. `PUT /api/edits`. Confluence, мессенджер, GitLab. Новая версия формулы. `riskScore`, карточка утилизации, цветовые пороги.

## Известные границы v1

- История исполнителя не приходит. Часы и открытые задачи висят на текущем assignee.
- Manifest не хранит запечатанные секунды. Цикл всегда считается из `statusChanges`.
- В burndown сгорают все terminal, включая отменённые: каталог не выделяет canceled отдельно.
- В примере снимка `metricVersions` по-прежнему перечисляет `completionVsCommitted`, а в массиве метрик примера лежит только `sprintFlow`. Это пример схемы, не выход движка.

Колонка due, которой не хватало контракту M0, в снимке есть.
