# Релиз-ноутс. M5. Один Jira

Веха M5. Живой сбор Jira Server / Data Center проходит через тот же разбор, что файловая выгрузка. Формулы не менялись.

Появилось:

- `sources.mode: live` читает спринт, поиск `/rest/api/2/search` и журнал задачи. Токен — Bearer из переменной `authEnv`;
- записанные тела `fixtures/m4/file-sprint` дают те же задачи и тот же `GET /api/sprint`, что `file`: закрытие до срока расходится по полночи, снятая задача имеет scope `removed`, сумма `storyPointsAtAdd` равна 8;
- редирект на другой хост обрывается, тело ответа с ошибкой в текст исключения не попадает;
- `--manifest` запечатывает задачи в роли `terminal` и снимает печать, когда роль уже другая;
- `Dockerfile` собирает один процесс. Секрет в образ не копируется. `serve` слушает только `127.0.0.1`.

Не входит: живой Cloud, Compose, планировщик, OIDC, Confluence, мессенджер, GitLab, React.
