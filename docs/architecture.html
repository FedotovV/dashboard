Архитектура и граница модулей

Одна установка превращает team.yaml и выгрузку в снимок, которому можно верить на разборе. Модуль знает только свой вход и свой выход. Общие файлы ходят через схемы, не через чужой код.

Контракты между модулями

Схемы уже стоят с M0. В начале M1 снимок дополняется полями, без которых движку некуда положить обещанные факты.

ФайлКто пишетКто читаетВ первом шаге
schema/team.schema.json человек и локальная модель по гиду config Необязательный breakStart, чтобы перерыв имел одно положение в дне
schema/canonical.schema.json коннектор; в M1 — автор фикстуры metrics Без смены смысла
schema/snapshot.schema.json orchestrator после metrics и edits web, история следующего build dueDate у задачи, trend, detail у метрики, хеш bundle
schema/edits.schema.json PM, позже PUT edits Build файл не переписывает
schema/manifest.schema.json orchestrator при приёмке пересчёта orchestrator Расхождение хеша останавливает build
docs/metric-catalog.md человек metrics, текст «Как считается» Уточнить положение перерыва и короткое пребывание. Версии формул не меняются

Первый шаг — движок

Подробные входы, выходы и золотые пары — в плане M1. Ниже порядок, в котором этот шаг закрывается.

0

Дописать снимок

Поля, которые каталог уже обещает, а схема снимка ещё не держит. Примеры и check_contracts.py остаются зелёными. Кода движка ещё нет.

1

Конфиг и одна арифметика времени

Окно дня, перерыв, праздник, полночь в зоне команды. Неизвестная версия каталога и несходящееся окно отклоняют файл.

2

Цикл и срок

Сумма роли active, не спан. Короткий заход, возврат в очередь, выход из terminal, due через полночь.

3

Состав спринта

Счётчики ролей, add на день 3, remove на день 7, завершение к составу на старте. Отмена остаётся в знаменателе.

4

Классификация

Ромб эпиков, цикл связей, метка tech поверх проектной головы, задача без головы → unknown.

5

Часы в статусе

Два параллельных тикета, масштаб дня, inherited и own в одном дне. Ноль прошедших рабочих дней → темп null.

6

Остальные карточки

Гигиена, список блокеров, люди с нулями, burndown только при полных SP, список эпиков.

7

Сборка

Слепок write-once, edits.json нетронут, смена statusMap без приёмки останавливает build. Текст «Как считается» показывает параметры фикстуры.

Источник правды по продукту — plan.md и metric-catalog.md. Эта страница их не заменяет: она показывает, какой модуль какой контракт держит. Порядок работ первого шага — m1-plan.md.
