# Универсальный проектный дашборд

Генератор командного дашборда для PM и PO. Сейчас проектируется контракт: одна команда поднимает установку из файла конфигурации и выгрузок Jira, Confluence, GitLab и мессенджера. Интерфейс первой версии считается на моделируемых данных. Те же формулы позже читают живые источники, в том числе Jira и Confluence на своих серверах.
